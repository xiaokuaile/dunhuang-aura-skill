# Workflows

Read this reference for **commercial-mode** image editing, multi-round revisions, visual suites, or client-facing production. For apsara generation or identity-preserving photo edits, read [Apsara mode](apsara-mode.md).

## Generate workflow

### Normalize the brief

Extract the deliverable type, aspect ratio, subject and exact count, text state, intended platform, must-preserve brand assets, forbidden motifs, and desired density.

Ask one question only when the missing answer would produce a different composition, such as text-led versus text-free.

### Pick a composition family

Use dual-anchor panorama for a full-frame text-free 5:2 cover. Use asymmetric product stage for one product. Use mural gateway for an editorial cultural visual. Use layered production studio for AI-image and creative-tool topics.

### Lock the system

Before generating a multi-image set, record:

- palette roles;
- ribbon color order and typical width;
- mural surface brightness;
- black-rock material;
- gold percentage;
- light direction;
- product-camera height;
- one allowed lotus treatment;
- one allowed caisson treatment.

### Generate the hero first

The hero defines the system. Do not generate all derivatives until the hero passes composition, palette, subject, text, and geometry checks.

### Derive, do not restart

For related assets, use the approved hero as a style reference. Change only one major variable at a time: aspect ratio, product, information hierarchy, crop, camera distance, or content role. Keep the visual system fixed.

## Edit workflow

### Translate feedback into one visible change

Examples:

- "左边也要有东西" becomes "add one large ceramic foreground anchor and three layered illuminated panels to the left third."
- "不要留白" becomes "extend architecture, panels, rocks, ribbons, and reflections across the full width."
- "去掉字" becomes "remove every letter, number, label, seal, logo, and interface microcopy, then reconstruct the underlying material."
- "再高级一点" becomes a choice among reduced ornament, stronger material realism, tighter palette, better lighting, or clearer hierarchy.

### Write the edit prompt in four blocks

1. Edit target.
2. Primary change.
3. Preserved invariants.
4. Avoid list.

Do not mix four separate feedback items in one pass. If the request includes remove text, fill space, replace product, and change palette, sequence the edits and inspect after each material change.

### Inspect drift

After each edit, compare subject count, product geometry, device geometry, camera angle, lighting direction, palette, ribbon flow, text state, and aspect ratio.

If an accepted object drifts, revert to the last accepted image and issue a narrower edit.

## Text-free workflow

Text can appear accidentally in five places:

1. Product label.
2. Phone or computer screen.
3. Poster or mural panel.
4. Decorative seal or architectural plaque.
5. Watermark-like corner mark.

Ban all five explicitly. Replace information-dense screens with image-led visual compositions. Inspect the image at full size, not only as a thumbnail.

## 5:2 balance workflow

Divide the canvas into left, middle, and right thirds.

- Each outer third must contain a visible anchor or intentionally quiet title area.
- The middle third must create flow, depth, or transition.
- In a text-free image, neither outer third may be empty.
- Balance visual weight, not identical object count.

A large pale ceramic vessel can balance a smaller bottle plus a tall dark phone because brightness and silhouette also contribute visual weight.

## Client production workflow

1. Get product references, logo, copy, sizes, channel list, and forbidden styles.
2. Generate three distinct composition directions.
3. Lock one direction.
4. Produce the hero.
5. Produce derivatives using the locked system.
6. Process feedback as single-variable edits.
7. Run the QA checklist.
8. Deliver original-size files plus a style note containing palette, prompt, and invariants.

Do not promise exact product fidelity from prompt-only generation. When geometry or packaging must remain exact, edit from the supplied product image or composite the generated environment around the original product.

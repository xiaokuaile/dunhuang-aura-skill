# QA checklist

Run this after every final generation or edit.

## Brief

- [ ] Deliverable type matches the request.
- [ ] Aspect ratio is correct.
- [ ] Text state is correct: exact text, placeholder-free, or text-free.
- [ ] Subject count and placement match the prompt.

## Composition

- [ ] One primary subject is obvious within one second.
- [ ] Foreground, middle depth, and background are distinguishable.
- [ ] A text-free 5:2 image has meaningful content on both sides.
- [ ] The middle of a panorama provides a visual path instead of a hard object wall.
- [ ] Panel sizes and depths vary.
- [ ] No important object is clipped by the frame.

## Style

- [ ] Charcoal, sand, cinnabar, malachite, lapis, and restrained ochre read as one palette.
- [ ] Gold remains an accent.
- [ ] Ribbons form one directional system.
- [ ] Lotus and caisson motifs are limited and purposeful.
- [ ] Dunhuang influence comes from color, material, and structure, not copied religious figures.
- [ ] The result reads as commercial art direction rather than a tourist poster.

## Objects

- [ ] Product silhouette is coherent.
- [ ] Caps, necks, bases, handles, and openings align.
- [ ] Product sits on a surface with a contact shadow.
- [ ] Glass, ceramic, metal, rock, and plaster respond differently to light.
- [ ] Device edges, bezel, perspective, and reflections are believable.
- [ ] No object is duplicated accidentally.

## Text and symbols

- [ ] Required copy is exact and appears the requested number of times.
- [ ] A text-free image contains no letters or numbers.
- [ ] Product labels contain no accidental glyphs when labels were not requested.
- [ ] Device screens contain no pseudo-readable microcopy.
- [ ] No logos, seals, QR codes, watermarks, or invented brand marks appear.

## Lighting

- [ ] One primary light origin is clear.
- [ ] Product highlights agree with that origin.
- [ ] Shadows and reflections point in physically consistent directions.
- [ ] Cave shadows retain readable detail.
- [ ] Glow is limited to luminous surfaces and reflected light.

## Exclusions

- [ ] No generic purple AI glow.
- [ ] No robot heads, AI brains, circuit boards, or code rain.
- [ ] No unexplained religious figures.
- [ ] No fantasy-game runes or magic effects.
- [ ] No excessive floral filler.
- [ ] No equal-card template layout.
- [ ] No cheap full-frame gold wash.

## Delivery

- [ ] Inspect at full resolution.
- [ ] Inspect at social-media thumbnail size.
- [ ] Confirm the saved file opens correctly.
- [ ] Preserve the original when delivering an edited variant.
- [ ] Record the final prompt and accepted invariants for future revisions.
